# 打开、关闭应用

1. **打开应用**：
	1. 终端输入程序名打开（但关闭终端，部分应用也会同时关闭）
	2. `Alt+F2`会弹出软件搜索弹窗（KRunner崩溃会导致用不了，注意修复）
	3. `Super(Win键)` 打开应用菜单（也可以直接打字输入应用名并回车键打开应用)
	4. `Alt+Ctrl+T` 打开终端模拟器
	5. `Super+I` 打开快速设置
	6. `Super+V` 打开剪切板
	7. `Super+B` 切换省电/平衡/性能模式
	8. `Alt+Ctrl+(F1~F6)` 切换虚拟控制台（kali中tty1和tty2是图形化界面，其余是纯文本控制台）
	- 各桌面环境快捷键大差不差，几乎能通用

2. **关闭应用**：
	1. `Alt+F4` 关闭应用
	2. `Ctrl+Q` 关闭应用（部分应用支持）
	3. `Ctrl+W` 关闭标签页or子窗口
	4. `Ctrl+C`  终止命令，也可以关闭终端打开的应用

# 分屏(移动)、切换窗口

1. **分屏、全屏、隐藏、移动窗口**：
	1. `Super+ ← ↑ ↓ →` 移动窗口位置及分屏
	2. `F11` 全屏及取消全屏
	3. `Super+D` 隐藏所有窗口（即显示桌面）
	4. `Super+H` 隐藏当前窗口
	5. `Super+PgUp` 最大化窗口
	6. `Super+PgDn` 最小化窗口
	7. `Super+点击拖动` 可以移动窗口（好处是不用点标题栏移动，配合触摸板会非常方便）
	-  **终端内分屏**：
		- `Shift+Ctrl+(` 左右分屏
		- `Shift+Ctrl+)` 上下分屏
		- `Shift+Ctrl+ ← ↑ ↓ →` 输入光标在窗口之间跳转

2. **切换应用**
	1. `Alt(+Shift)+Tab` 打开窗口切换器（先按`Alt`，后点击`Tab`选择窗口，加`Shift`可以反向选择）
	2. `Super+Tab` 3D窗口切换（没有的话，则和`Alt(+Shift)+Tab`效果一样）
	3. `Alt+~(Tab 上方那个键)` 仅在同一应用的多个窗口之间切换（比如两个 Firefox 窗口之间）
	4. `Ctrl+F9` 平铺展示当前工作区窗口
	5. `Ctrl+F10` 平铺展示所有工作区窗口
	- 切换窗口后，光标也会随之进入窗口，所以可以做到快捷输入。

# 快速切换工作区(虚拟桌面)

1. `Ctrl+F1至F4` 快速切换工作区
2. `Super+G` 所有工作区总览
3. 触摸板三指左右滑动切换工作区（在提前创建了多个工作区的情况下）

# 锁屏关机

1. `Ctrl+Alt+Delete` 注销/关机菜单
2. `Super+L` 锁屏

# 杂项
1. 无名指中指放在触摸板上不动，食指移动可以放大缩小屏幕
2. 光标移至左上角可打开工作区+窗口总览

> 多结合 `Super` 键按一按其他键，还能发现挺多快捷键的
